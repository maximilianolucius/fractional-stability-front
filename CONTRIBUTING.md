# Contributing

This is a research repository. Contributions must preserve traceability.

## Literature additions

Provide:

1. persistent identifier/source;
2. search provenance when known;
3. screening status;
4. bibliographic facts separately from interpretation;
5. theorem-level claims precisely when relevant.

## Frontier claims

Novelty or absence claims require an evidence trail. Mark unverified ideas as hypotheses.

## Taxonomy changes

Update `docs/taxonomy.md` and record material changes in `STATUS.md`.

## Reproducibility

Derived tables and figures should be regenerable from committed source data and scripts whenever practical.

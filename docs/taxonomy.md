# Working Taxonomy

## 1. System class
linear autonomous; linear time-varying; nonlinear autonomous; nonlinear time-varying; delayed; neutral; stochastic; impulsive; switched/hybrid; discrete fractional; networked/multi-agent.

## 2. Fractional structure
commensurate; incommensurate; Caputo; Riemann–Liouville; Grünwald–Letnikov; variable order; distributed order; uncertain order; other.

## 3. Stability notion
asymptotic; Mittag-Leffler; Lyapunov; finite-time; input-to-state; robust; synchronization; consensus; D-stability; diagonal stability; structural/sign stability.

## 4. Representation / method
Jacobian/spectral; characteristic equation; state-space; LMI; Lyapunov function; comparison principle; frequency domain; matrix measure; graph/Laplacian; monotone/positive; qualitative matrix.

## 5. Matrix/network structure
dense; sparse; positive/Metzler; M-matrix-related; diagonally stable; D-stable; sign constrained; interval/uncertain; Laplacian; directed; signed; switching; multilayer/temporal.

## 6. Result strength
exact characterization; necessary-and-sufficient; necessary; sufficient; conservative computational test; asymptotic approximation; numerical evidence; counterexample/impossibility.

## 7. Theorem scope
scalar; fixed low dimension; arbitrary finite dimension; topology-specific; matrix-class-specific; local nonlinear; global nonlinear.

## 8. Frontier gap
existence; generalization; necessity/exactness; structural unification; bridge; robustness; computational complexity; proof/regularity; counterexample/sharpness.

## 9. Allee structure
weak; strong; component; demographic; multiple/double; two-threshold; mechanism-composed; spatial/network-induced; stochastic/environmental.

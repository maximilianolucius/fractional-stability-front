# Executive conclusion

The seven-candidate portfolio should be reduced to **three serious theorem families**.

## Serious survivors

### S1 — DA-MEMORY-FIBER (C1) — RETAIN

Residual:

> characterize when one physically reachable current-state fiber
> \[
> e_0^{-1}(x)\cap\mathcal R_\alpha
> \]
> intersects distinct asymptotic basins, especially extinction and survival/coexistence basins, in positive multidimensional Caputo systems.

The new hostile search through:
- noninjective observables;
- factor maps;
- partial observation;
- indistinguishable present states;
- identical outputs with distinct omega-limits

did not identify a theorem that resolves this Caputo reachable-fiber basin question.

Direct prior already kills weaker claims:
- same-present/different-memory is direct prior;
- history-dependent tipping landscapes are close prior.

But the **opposite-basin fiber theorem** survives.

### S2 — ROBUST-THRESHOLD + MECHANISM-PERSISTENCE-FILTER (C2 + C6) — MERGE AND RETAIN

Residual:

> uncertainty-uniform survival/extinction regions, basin-relative persistence, separator enclosures and bistability preservation for positive Caputo families under simultaneous parameter/order/mechanism uncertainty.

C6 should not remain independent.

The new hostile search found mature:
- viability kernels;
- discriminating kernels;
- robust capture basins;
- robust invariant-set theory;
- classical robust permanence.

This increases killer risk for generic robust-set claims.

At the same time, no direct theorem was found for the full fractional object:
- memory state;
- uncertain fractional order;
- strong-Allee multibasin geometry;
- common survival/extinction regions.

Multiple-Allee mechanism composition is better treated as an **application/uncertainty layer inside C2** than as a separate mathematical frontier.

### S3 — STOCH-PERSISTENCE-EXIT + PERSISTENT-SWITCHING (C3 + C4) — MERGE AND RETAIN, WITH NARROWING

Residual:

> stochastic persistence/extinction and rare basin exit in positive fractional-memory multistable systems, including stochastic regime switching with inherited/persistent memory.

Two new 2026 sources materially change the comparison.

1. **Földes–Stacy 2026, arXiv:2601.19145**  
   develops a general stochastic-persistence framework in infinite dimensions, including stochastic functional differential equations.

2. **Herrera-Marín 2026, arXiv:2605.00729**  
   studies stochastic regime switching in nonlinear operator-valued Volterra systems with completely monotone long-memory kernels, proving a nontrivial annealed/quenched instability theory.

Consequences:

- “stochastic persistence in infinite-dimensional lifted memory spaces” is no longer a safe novelty premise by itself;
- “persistent long-memory regime switching” is no longer empty.

The surviving high-value residue is narrower:

- apply/adapt persistence theory to the **fractional stochastic Volterra lift with extinction boundary**;
- derive **basin-relative** persistence appropriate to strong Allee;
- move from existing path LDP to **quasipotential / exit-time / rare-extinction theorems**;
- characterize how fractional memory changes stochastic extinction risk;
- treat regime switching as a special stochastic forcing mechanism within that program.

C4 therefore loses independence and should merge into C3.

# Candidate-by-candidate audit

## C1 — DA-MEMORY-FIBER

### Exact residual

For a positive autonomous multidimensional Caputo system with multiple asymptotic outcomes, determine whether

\[
\exists x,\phi,\psi:
\quad
\phi,\psi\in\mathcal R_\alpha,\quad
e_0(\phi)=e_0(\psi)=x,
\]

but

\[
\phi\in\mathcal B(A_1),\qquad
\psi\in\mathcal B(A_2),\qquad
A_1\ne A_2.
\]

### Strongest direct prior

- Cong–Tuan: reachable same-present collisions in \(d\ge2\).
- Doan–Kloeden: memory-state semigroup.
- Khalighi et al. 2026: history-dependent bistable stability landscapes.

### New hostile search

Searches in:
- partial observation;
- factor maps;
- indistinguishable states;
- noninjective observables;
- same output/different attractor;
- omega-limit ambiguity.

No source was found that turns the exact reachable Caputo basin-fiber statement into a direct corollary.

### Assessment

- **Novelty survivability:** high-moderate.
- **Mathematical depth:** high if a structural theorem is required, low if only one numerical example.
- **FDE centrality:** very high; the fiber exists because the current state is a noninjective projection of memory state.
- **Double-Allee proximity:** DIRECT.
- **Scope richness:** high if one studies fiber geometry, basin intersection, order dependence and sufficient/necessary conditions.
- **Killer risk:** moderate.
- **Model-artifact risk:** low after restricting to \(\mathcal R_\alpha\).
- **Empirical route:** moderate; requires matched current population states with different controlled histories.
- **Literature velocity:** moderate.
- **Search confidence:** high-moderate.

### Disposition

**RETAIN.**

For positive stochastic Caputo/Volterra memory systems:

- singular stochastic-Volterra lifts with extinction boundary;

- **Scope richness:** very high.
- **Killer risk:** high and increasing.
- **Model-artifact risk:** moderate because positivity/noise convention must be physically valid.
- **Empirical route:** strong conceptually; extinction times/environmental noise can be data-linked.

**RETAIN, narrowed toward basin-relative persistence + rare exit rather than generic stochastic persistence.**

# Cross-candidate overlap test

## C1 vs C3

Common deep object:

\[
\text{memory-state basin geometry}.
\]

C1 asks whether the projection from memory state to current population identifies states in different deterministic basins.

C3 asks how stochastic trajectories exit or persist relative to those basins.

They should **not be merged operationally** because:
- C1 is deterministic geometric;
- C3 is probabilistic/rare-event.

But C1 can provide the deterministic geometric substrate for C3.

## C1 vs C5

C5 is better viewed as potential local machinery for how basin boundaries are organized near nonhyperbolic points.

**Do not retain C5 independently.**

## C2 vs C3

Both concern uncertainty, but the quantifiers differ.

C2:
\[
\forall \xi\in\mathcal U
\]
robust/adversarial family guarantee.

C3:
probabilistic law, occupation, exit and rare-event asymptotics.

Do not merge.

## C2 vs C4

Regime switching can be viewed as temporal parameter uncertainty, but persistent memory and a stochastic switching process add pathwise correlation and history.

C4 aligns more naturally with C3 than C2.

## C3 vs C4

**MERGE.**

C4 is a special stochastic-memory forcing architecture.

## C6 vs C2

**MERGE.**

Mechanism composition can define structured parameter/uncertainty sets and biologically interpretable failure modes inside C2.

## Five results that most changed the map

### 1. Incommensurate stability is no longer a thin exact-theory branch

Diethelm, Hashemishahraki, Thai & Tuan (2024), DOI **10.1016/j.jmaa.2024.128642**, gives:
- N&S stability for rational incommensurate systems;
- a rational-approximation framework for general orders;
- equivalence with the fractional spectrum;
- constructive linear analysis;
- nonlinear linearized stability in arbitrary finite dimension.

**Consequence:** OPPORTUNITY-FS-02 must be narrowed away from generic local/incommensurate stability.

### 2. Converse nonlinear fractional stability is real, not merely aspirational

Gallegos–Duarte-Mermoud (2019), DOI **10.3906/mat-1808-75**, gives converse Lyapunov/ML stability results.

Guo et al. (2025), DOI **10.1016/j.jfranklin.2024.107414**, establishes fractional input-to-state stability and a converse Lyapunov theorem.

**Consequence:** a broad “missing converse Lyapunov theory” claim is false.

### 3. Robust linear uncertainty has exact modern results

Zheng 2017 already handles interval coefficient/order uncertainty.

Zhang–Lu (2023), DOI **10.1016/j.cnsns.2023.107511**, adds N&S robust stability for mixed multi-parameter + norm-bounded uncertainty.

**Consequence:** the likely robust frontier is nonlinear threshold/persistence, not generic linear robust stability.

### 4. Fractional delay theory now has an exact N&S result

Zhang, Jin, Lu & Zhu (2025), DOI **10.1109/LCSYS.2025.3620881**, gives a necessary-and-sufficient **delay-independent** stability condition and an exact generalized-KYP/LMI representation without additional conservatism.

**Consequence:** delay remains interesting, but the target must be delay-dependent, neutral, nonlinear or multi-order—not generic delay stability.

### 5. Bifurcation language has a foundational consistency problem

Tavazoei–Haeri (2009), DOI **10.1016/j.automatica.2009.04.001**, proves nonexistence of nonconstant exactly periodic solutions for finite-lower-terminal autonomous Caputo systems.

Doan–Kloeden (2022), DOI **10.1007/s13540-022-00030-6**, rigorously treats attractors and scalar saddle-node/pitchfork bifurcations for a structured Caputo class.

**Consequence:** the enormous application literature calling eigenvalue-sector crossings “Hopf bifurcations” requires careful theorem-level reconciliation. This is one of the strongest breadth-search frontier signals.

## Most under-mapped branches

### D8 — switched / stochastic / hybrid
Current papers are mostly architecture-specific sufficient Lyapunov/LMI/dwell-time results. A unified exact/converse architecture was not identified.

### D10 — rigorous bifurcation
The branch contains both hard nonperiodicity theorems and many applied Hopf claims. This requires a dedicated conceptual/theorem map.

### D11 — persistence/permanence
Integer-order dynamical systems have abstract N&S permanence theory; the searched fractional literature was predominantly model-specific.

### D12 — variable/distributed order
The branch is moving rapidly:
- distributed-order Lyapunov theory in 2017;
- new time-varying-order Lyapunov theory in 2025;
- unified nonlinear distributed-order continuous/discrete framework in 2026.

The exact/converse frontier cannot be inferred from older reviews alone.

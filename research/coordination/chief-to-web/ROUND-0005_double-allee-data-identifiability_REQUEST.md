# ROUND-0005 — WEB SEARCH REQUEST

**From:** CHIEF RESEARCHER

## Objective

Determine whether a **real, reusable ecological dataset** can support a serious identification problem involving multiple component Allee effects, demographic threshold emergence, and—only if justified—memory/fractional dynamics.

The island fox is the first lead, not a presumed winner.

## Exact questions

### Island fox

1. Is the 1988–2000 dataset underlying Angulo et al. 2007 publicly downloadable?
2. Search:
   - supplementary files;
   - Dryad/Zenodo/Figshare/OSF;
   - university/institution repositories;
   - later papers reusing the same data;
   - thesis/dissertation archives;
   - government/conservation datasets;
   - author data statements.
3. What is the actual data structure?
   - islands/populations;
   - years/time points;
   - individual versus aggregate observations;
   - survival estimates;
   - breeding proportions;
   - density;
   - eagle/predation variables;
   - missingness;
   - interventions.
4. Would those observations permit one-component versus two-component model discrimination?
5. Is there enough temporal depth for any memory parameter to be estimated independently of environmental autocorrelation?

### Alternative systems

6. Find at least 3 alternative open or realistically obtainable datasets with:
   - repeated low-density observations;
   - demographic-component measurements;
   - plausible multiple Allee mechanisms;
   - sufficient temporal/spatial replication.
7. Prioritize:
   - spongy/gypsy moth;
   - reintroduction/conservation datasets;
   - plant pollination + inbreeding;
   - social/cooperative vertebrates;
   - fisheries/depensation if multiple mechanisms are observable.
8. Search for datasets already used in Allee-effect parameter estimation.

### Identifiability prior art

9. What structural-identifiability results exist for Allee models?
10. What practical-identifiability/model-selection work compares strong/weak/no-Allee mechanisms?
11. What identifiability theory exists for fractional-order ecological models?
12. What results address confounding between:
   - fractional memory;
   - delay;
   - colored environmental noise;
   - latent states;
   - time-varying parameters?
13. Is joint identification of component mechanisms + threshold + fractional order already covered?

## Working hypothesis to challenge

A strong applied-mathematics opportunity may exist only if a dataset and observation design permit meaningful discrimination among mechanism count, demographic threshold geometry, and memory.

Try to show that this is impossible or already solved.

## Scope

Primary empirical ecology sources, official repositories, dataset papers, inverse-problem/identifiability literature, and fractional system identification.

## Exclusions

- synthetic datasets;
- papers saying “data available on request” without any evidence the data remain obtainable should be marked uncertain;
- abundance-only datasets with too few low-density observations unless they offer unusual replication;
- fractional-model papers using arbitrary/hypothetical parameters.

## Evidence required

For each dataset:

- stable source/repository;
- access/licence;
- raw vs processed status;
- temporal span/resolution;
- number of populations/sites;
- measured state/demographic variables;
- low-density coverage;
- missingness/error if documented;
- interventions;
- whether multiple mechanisms are separately observed;
- suitability for threshold estimation;
- suitability for memory estimation;
- primary limitations.

For identifiability papers:

- model class;
- structural versus practical identifiability;
- exact result/method;
- data design;
- relevance to our candidate;
- whether the result threatens novelty.

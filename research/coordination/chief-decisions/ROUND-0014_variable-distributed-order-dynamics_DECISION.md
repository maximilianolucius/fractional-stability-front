## 1. Executive decision

ROUND-0014 shows that “variable/distributed-order dynamics” is not one homogeneous field.

The maturity split is decisive:

- **fixed distributed order:** strong operator/resolvent theory, substantial exact linear stability, and nonlinear Lyapunov stability already exist;
- **prescribed variable order:** existence, continuation, comparison and Lyapunov stability are active, but global process/cocycle theory is thin;
- **state-dependent order:** foundational theory exists, global dynamical-system architecture remains sparse;
- **distributed-variable order:** still comparatively foundational/modeling-heavy.

Therefore broad claims that distributed-order or variable-order systems “lack stability theory” are false.

The real residual begins after equilibrium-centered stability.

## 2. What is closed as novelty

The following are not viable broad novelty claims:

- distributed-order linear stability;
- distributed-order state/evolution representation;
- nonlinear distributed-order Lyapunov stability;
- variable-order existence/uniqueness;
- variable-order comparison principles;
- variable-order equilibrium stability.

These all have direct prior art.

## 3. What survives

The strongest theorem-level residuals are:

### D14-A — variable-order process/cocycle architecture
A general history-state/process theory for prescribed time-varying order, with continuity, compactness and dissipativity.

### D14-B — state-dependent-order global dynamics
A rigorous state-space framework when the memory exponent depends on the evolving state.

### D14-C — distributed-order global nonlinear dynamics
Beyond resolvent/decay and Lyapunov equilibrium stability:
- absorbing sets;
- global basins;
- attractors;
- persistence/extinction;
- dependence on the order-weight distribution.

### D14-D — nonhyperbolic reduction
Center-manifold / normal-form / Lyapunov–Schmidt theory for variable/distributed-order operators.

### D14-E — positive threshold systems
General persistence/extinction theory for VO/DO systems, including strong-Allee-compatible basin-relative notions.

### D14-F — model-class distinguishability
When fixed-order, multi-term, continuous distributed-order, and variable-order models can be distinguished from observations.

## 4. Double-Allee assessment

The Double-Allee connection is currently weaker than for:
- D6 robust threshold geometry;
- D10/D11 basin-memory/persistence;
- the earlier mechanism-space candidate.

No direct variable/distributed-order Double-Allee theorem program was identified.

This absence is not enough.

A scientifically convincing bridge would need a reason that multiple Allee mechanisms genuinely carry:
- heterogeneous memory scales;
- a distribution of memory exponents;
- or an evolving memory law.

Otherwise D14 risks becoming operator decoration.

## 5. Applied/identifiability warning

The flexibility of variable/distributed-order models increases the burden of model discrimination.

Existing inverse results show recoverability within selected VO/DO model classes, but that does not establish cross-class distinguishability between:
- one fixed order;
- multiple discrete orders;
- continuous distributed order;
- variable order.

This materially lowers D14's immediate attractiveness as the preferred Double-Allee opportunity.

## 7. Why the next round moves to D8

The next under-mapped branch with stronger extinction/persistence relevance is:

> **stochastic, randomly switched, and hybrid fractional dynamics.**

This branch is directly relevant to Allee extinction because noise and regime changes can induce crossing/tipping across survival thresholds.

However, the terminology is dangerous.

“Fractional stochastic” may mean:
1. a **time-fractional Caputo derivative** plus stochastic forcing;
2. an ordinary evolution equation driven by **fractional Brownian motion**;
3. a stochastic PDE with a **spatial fractional Laplacian**;
4. a system with random switching times but deterministic fractional dynamics between switches.

These must not be conflated.

Current verification already shows:
- direct stochastic Allee persistence/extinction literature in ordinary SDEs;
- direct 2026 random-switching fractional stability;
- Caputo-type stochastic FDE existence/finite-time stability results;
- random-attractor literature for other meanings of “fractional stochastic”.

Therefore ROUND-0015 must reconstruct the exact taxonomy before any gap claim.

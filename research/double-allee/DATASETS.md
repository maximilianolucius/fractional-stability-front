# Double Allee — Dataset Inventory

For every candidate dataset record:

- source and citation;
- access/licence;
- species/system;
- observed variables;
- temporal resolution;
- spatial structure;
- sample size;
- missingness/error;
- whether two-threshold behavior is identifiable;
- whether fractional memory is identifiable;
- suitability for calibration;
- suitability for out-of-sample validation;
- limitations.

A dataset should constrain the science, not merely decorate the paper.

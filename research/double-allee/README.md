# Double Allee Research Branch

This branch seeks a **mathematically deep, defensibly novel applied-mathematics direction involving Double Allee dynamics**.

The target is not a cosmetic fractionalization of a known population model.

A strong direction should ideally connect an ecologically meaningful Double Allee mechanism to one or more of:

- structural stability;
- D-stability or diagonal robustness;
- network topology;
- bifurcation/threshold geometry;
- fractional memory;
- persistence/extinction theory;
- uncertainty;
- identifiability/inverse problems;
- a real ecological dataset.

## Required outputs

- `STATE_OF_ART.md`
- `TERMINOLOGY.md`
- `CANDIDATE_DIRECTIONS.md`
- `DATASETS.md`
- `NOVELTY_AUDIT.md`
- `PRIMARY_DIRECTION.md`

The primary direction must survive an adversarial novelty search and mathematical feasibility review before it is treated as the project target.
